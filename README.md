# Análisis comparativo de algoritmos de clustering

## Descripción del proyecto

Este proyecto tiene como objetivo implementar y comparar tres algoritmos de aprendizaje automático no supervisado: K-Means, DBSCAN y Clustering Jerárquico, con el propósito de identificar agrupaciones y analizar patrones dentro de diferentes conjuntos de datos.

El trabajo se desarrolló utilizando Python y la biblioteca Scikit-learn, mediante Google Colab.

## Algoritmos implementados

- **K-Means:** agrupamiento mediante centroides.
- **DBSCAN:** agrupamiento basado en densidad y detección de ruido.
- **Clustering Jerárquico:** agrupamiento progresivo mediante dendrogramas.

## Conjuntos de datos utilizados

- **Wine:** 178 observaciones y 13 variables.
- **Make Moons:** 500 observaciones y 2 variables.
- **Iris:** 150 observaciones y 4 variables.
